# Results

Output of `scripts/evaluate.py` (for example `emf_eval_results.json`) and of the figure scripts is written
here or next to the working directory, and is git-ignored. `scripts/make_figures.py` and
`scripts/dft_stability.py` read the evaluation JSON.

If you want a small reference result in the repository, copy one JSON here **and** remove it from the ignore
rules explicitly (`!results/reference_eval.json`) so it is a deliberate choice.
